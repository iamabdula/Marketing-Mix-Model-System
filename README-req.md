
# Marketing Mix Model System

### Data Processing and Storage
Design and implement a data ingestion pipeline for marketing spend and sales data.
Implement data validation and cleaning mechanisms.
Consider efficiency in data storage and retrieval.

### Model Service
Implement a service that trains and serves a Marketing Mix Model.
Design this service to be modular, allowing for easy swapping of different model types in the future.
Consider performance optimization in your implementation.

### API Layer
Create a RESTful API using FastAPI that accepts marketing spend data and returns sales predictions.
